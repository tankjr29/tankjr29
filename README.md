# 🚀 Projets phares

## CampusNav — Navigation intelligente sur le campus UFHB

Application mobile de navigation du campus UFHB, conçue pour aider les étudiants et visiteurs à se repérer plus facilement dans l’université.

### Ce que j’y ai mis en place

- carte interactive et navigation intelligente
- recherche et localisation de points d’intérêt
- architecture mobile + API + back-office
- expérience utilisateur pensée pour le terrain

### Stack

React Native • Expo • Node.js • Express • Sequelize • MySQL • Mapbox • Firebase • Axios

---

## IoT Smart Parking & Edge Security

Projet IoT orienté sécurité et supervision intelligente, avec des capteurs, une orchestration MQTT, des dashboards de monitoring et des mécanismes de protection embarqués.

### Stack

ESP32 • MQTT • Node-RED • InfluxDB • Grafana • Docker

---

## Load Balancing DNS & Web

Infrastructure réseau haute disponibilité avec cluster DNS et fermes web, simulée dans un environnement de lab avec équilibrage et sécurité réseau.

### Stack

Kathara • BIND9 • Apache2 • iptables • Docker
